NT Shield Central 1.3.1
=======================
Product      : NT Shield Central
Service      : NTShieldCentral
Default URL  : https://localhost:7443
Syslog UDP   : 5514
Install dir  : C:\Program Files\NT Shield Central
Data dir     : C:\ProgramData\NTShield\Server
Database     : C:\ProgramData\NTShield\Server\central.db (SQLite lab/small deployment)

SECURITY FILES
--------------
Protected secrets (SYSTEM/Administrators only):
  C:\ProgramData\NTShield\Server\secrets.json

Public Central certificate for Agent trust:
  C:\ProgramData\NTShield\Server\certs\central.cer

Private Central certificate:
  C:\ProgramData\NTShield\Server\certs\central.pfx
  Do not distribute this file.

Public discovery metadata only:
  C:\ProgramData\NTShield\connection.json
  This file must not contain EnrollmentToken, OperatorApiKey or signing private keys.

AUTHENTICATION
--------------
Health is public:
  GET https://localhost:7443/api/v1/health

All other data/control APIs require the correct credential scope:
  EnrollmentToken : first Agent registration only
  Per-Agent key   : heartbeat and telemetry ingest only
  OperatorApiKey  : Control Center, incidents, policy, audit and response

Read EnrollmentToken and OperatorApiKey from protected secrets.json as Administrator.
Never copy secrets.json to an endpoint.

REMOTE AGENT PROVISIONING
-------------------------
1. Use the real Central DNS/IP present in the certificate SAN:
     https://<central-host>:7443
2. Copy central.cer (public) or use a publicly trusted certificate.
3. Supply EnrollmentToken through a protected provisioning channel.
4. The Agent receives and stores a per-Agent API key after enrollment.
5. Do not enable AllowUntrustedServerCertificate outside an isolated migration lab.

Example:
  NTShield-Agent-Setup-1.3.1.exe /VERYSILENT ^
    /CentralUrl=https://<central-host>:7443 ^
    /EnrollmentToken=<token> ^
    /CaCertificatePath=C:\Secure\central.cer

CONTROL CENTER
--------------
URL              : https://<central-host>:7443
Operator API Key : read OperatorApiKey from protected secrets.json
